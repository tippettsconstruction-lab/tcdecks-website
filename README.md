# TC Decks website

Static site for [tcdecksutah.com](https://www.tcdecksutah.com), built with [Astro](https://astro.build) and hosted on Netlify.

## Editing
- Business details, services, cities and reviews: `src/data/site.ts`
- Pages: `src/pages/`
- Blog posts: add a Markdown file to `src/content/blog/`, then run `node scripts/build-redirects.mjs` so its old URL stops redirecting.

## Commands
- `npm install`, then `npm run dev` for a local preview at http://localhost:4321
- `npm run build` writes the site to `dist/`

## Redirects
`public/_redirects` is generated by `scripts/build-redirects.mjs` from the list of old blog URLs in `scripts/old-blog-slugs.txt`. Every old URL 301-redirects to the closest new page so search rankings carry over.
